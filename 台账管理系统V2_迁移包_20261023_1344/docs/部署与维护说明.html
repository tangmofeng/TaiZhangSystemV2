部署与维护说明

一、首次部署

  1. 安装 Python 3.11（勾选 Add to PATH）；离线部署必须用 3.11（wheels 离线包为 cp311 构建）
  2. 解压迁移包到 D:\TaiZhangSystemV2
  3. 双击 install.bat 自动装依赖（在线镜像→官方源→离线 wheels 三级兜底）、开防火墙、设开机自启
  4. 浏览器访问 http://服务器IP:8090，admin/admin123 登录

二、日常启动/停止

启动：Start-Process python.exe -ArgumentList "D:\TaiZhangSystemV2\server\app.py" -WorkingDirectory "D:\TaiZhangSystemV2" -WindowStyle Hidden
停止：Get-Process python | Stop-Process -Force

三、开机自启

已通过任务计划程序添加，开机自动运行。查看：任务计划程序 → 台账管理系统V2。

四、防火墙

已放行 8090 端口 TCP。其他机器访问：http://服务器IP:8090。

五、升级迁移

  1. 停服务
  2. 备份 data\system.db
  3. 替换 server/ 和 public/ 目录（不要动 data/）
  4. 启动服务

六、改 IP/端口

端口改 app.py 末尾 app.run(port=8090)，同步改防火墙规则。
